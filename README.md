# Angela T. Ibasco — Virtual Assistant Portfolio Website

This package contains a responsive portfolio website built with semantic HTML5, CSS3, and vanilla JavaScript.

## Files

- `index.html` — complete page content and semantic structure
- `style.css` — complete design system and responsive styling
- `script.js` — mobile navigation, subtle reveal behavior, active navigation, and image fallbacks
- `assets/ASSET-INSTRUCTIONS.txt` — exact mapping for the screenshots already used in Angela's Notion portfolio

## Content strategy

The website preserves the entry-level positioning in the Notion portfolio. Demonstration projects remain labeled as demonstration projects. The library system remains labeled as a systems project. No client names, testimonials, work history, statistics, or claims were invented.

The site structure is:

1. Home
2. About
3. Support I Can Provide
4. Selected Projects
5. Skills & Tools
6. How I Work
7. Resume
8. Contact

## Visual direction

The palette uses:

- `#F8B2B2` soft pink for highlights and focus
- `#AF719D` muted mauve for supporting accents
- `#8B639B` purple for secondary accents
- `#403D88` deep indigo for navigation, headings, and strong contrast

Neutral white and off-white backgrounds prevent the page from becoming overly purple.

## Local preview

Open `index.html` directly in a browser. No server is required.

For the final portfolio, add the eight project images listed in `assets/ASSET-INSTRUCTIONS.txt`.
